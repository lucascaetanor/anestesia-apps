# Apps de Anestesiologia

Ferramentas educacionais em HTML, instaláveis como app (PWA). Dr. Lucas Caetano.

| App | Pasta |
|---|---|
| SIM PED — Simulador de Anestesia Pediátrica | `pediatrica/` |
| SIM TCI — simulador de infusão alvo-controlada | `tci/` |
| Guardião — detector de acesso ao celular (instala como "Relógio") | `antiespiao/` |
| Ficha Anestésica — pré, intra e SRPA com geração de PDF | `ficha/` |

Para atualizar um app: substitua o `index.html` da pasta e incremente a versão do cache no `sw.js` da mesma pasta.
